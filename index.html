Module 01：什麼是 AI Agent？從對話顧問到數位專案經理

經典公式：AI Agent = LLM (核心大腦) + Planning (規劃與反思) + Memory (長短期記憶) + Tools (外部工具調用)。傳統 LLM 是被動問答，而 AI Agent 則是目標導向（Goal-Driven）的數位勞動力。

比較維度 傳統 Chatbot (LLM) 傳統 RPA 流程機器人 AI Agent (自主代理)
驅動方式人類逐句輸入 Prompt死板的固定 If-Else 規則給定終極 Goal 後自主拆解步驟
異常應變產生幻覺或中斷網頁改版即報錯停機透過 ReAct 觀察錯誤並動態修正參數
外部行動力僅能輸出文字/圖片可點擊固定介面主動決定呼叫哪支 API / 資料庫 / 搜尋工具

    "name": "calculateCampaignROI",
    "args": {

      "cvr": 0.012

Module 05：TONY 老師獨創「4R 流程重構法則」與 Multi-Agent 多代理協作架構

          
        

        

          
1. Recognize (盤點識別)拆解高重複、跨系統查詢的企業痛點節點。

          
2. Redesign (重構分工)將單一巨型 Prompt 拆解為「策略、文案、視覺、審核」專業職能 Agent。

          
3. Reflect (反思閉環)設計量化檢核點（如 ROAS ≥ 2.0、法規禁用詞 0 違規）與局部退件機制。

          
4. Realize (價值變現)將最終核准之 Shared State 自動排版輸出為高階主管 Word 決策報告。
